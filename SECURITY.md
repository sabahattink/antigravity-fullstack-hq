# Security Policy

## Supported Versions

Full Stack HQ is a configuration repository rather than a runtime service.
Security updates cover installer behavior, generated instruction files, and
examples that could cause unsafe host-agent behavior.

| Version | Supported |
| ------- | --------- |
| 1.1.x | :white_check_mark: |
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting for this repository:

https://github.com/sabahattink/antigravity-fullstack-hq/security/advisories/new

Include the affected version, host, installer option, exact reproduction
steps, and potential impact. Do not publish credentials, personal data, or an
exploit before maintainers have had a chance to respond.

If private reporting is unavailable, open a minimal public issue without
sensitive details and ask maintainers for a private channel.
